# Automation Setup

## Goal

Automation should remove repeated founder and operator work without obscuring what the system is doing.

## Automation Domains

### Product Automation

- task activation and close-out support
- doc-template scaffolding
- decision-log prompting
- backlog hygiene

### Growth Automation

- competitor monitoring capture
- content calendar support
- launch checklist reminders
- funnel metric collection

### Engineering Automation

- CI and validation
- deployment workflows
- smoke detection
- incident-to-task creation
- environment bootstrap

### Reliability Automation

- uptime checks
- post-deploy health probes
- cron monitoring
- recovery workflows

## Automation Rules

- start with high-frequency, low-judgment work
- keep automations observable and reversible
- prefer repo-visible state over hidden SaaS automation where possible
- always preserve a manual recovery path
