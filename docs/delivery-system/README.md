# Delivery System

This section contains the reusable delivery and engineering operating model that Product OS can export to other products.

It is intentionally separate from:

- `docs/platform/`, which describes current implemented Product OS platform behavior
- `docs/startup-os/`, which describes Product OS as a startup product and operating system
- `docs/product-model/`, which contains reusable product documentation guidance and templates

## Scope

This layer covers:

- task lifecycle and task anatomy
- grounding rules for AI-assisted implementation
- close-out and validation contracts
- task templates and Codex prompt templates
- delivery-system patterns that can be rolled out into future repos

Generalize patterns here only after they are proven in a real product repo.
