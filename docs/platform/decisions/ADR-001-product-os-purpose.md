# ADR-001: Product OS Purpose

## Status

Accepted

## Context

Product work needed to be operated as a connected system rather than isolated records.

## Decision

Use Product OS to model work as a Product-centered graph with first-class WorkItem, Relationship, Signal, KPI, and Decision concepts.

## Consequences

- Strategy and execution can be traced through explicit graph connections.
- Operational feedback can create or update follow-up work.
- Documentation and data model align on the same core terms.
